Enter your Supabase project credentials to get started. Your data will be stored privately in your own database.
Get these from supabase.com/dashboard → your project → Settings → API Keys. Use the publishable key (new projects) or the anon key under the Legacy tab.

First, run this SQL in your Supabase SQL Editor:
CREATE TABLE tasks (
  id uuid DEFAULT gen_random_uuid() PRIMARY KEY,
  text text NOT NULL,
  done boolean DEFAULT false,
  date text NOT NULL,
  created_at timestamptz DEFAULT now()
);
